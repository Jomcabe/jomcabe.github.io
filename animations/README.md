# VAM overview

The Manim source for `../VAM_Tomography.mp4`. This is a silent, captioned
introduction to the rotating-vat, tomographic form of volumetric additive
manufacturing, also called computed axial lithography (CAL).

It follows one example part through a digital model, calculated light patterns,
rotation and exposure, accumulated light dose, and removal from the resin.
All text and illustrations are generated by Manim. The only credit is a small
`Jocabe` in the lower-right corner.

## Render

Install Manim's platform dependencies, then:

```sh
python -m pip install -r animations/requirements.txt
manim -qh --fps 30 animations/vam_overview.py VAMOverview
```

Manim writes the render under `media/videos/vam_overview/1080p30/`.
The published copy is H.264, 1920 × 1080 at 30 fps, with fast-start metadata
for playback on the website. The first frame is also used as the video poster.

To prepare the web copy with FFmpeg:

```sh
ffmpeg -i media/videos/vam_overview/1080p30/VAMOverview.mp4 \
  -c:v libx264 -crf 23 -preset slow -tune animation \
  -pix_fmt yuv420p -movflags +faststart -an VAM_Tomography.mp4
ffmpeg -i VAM_Tomography.mp4 -frames:v 1 -q:v 2 VAM_Tomography.jpg
```

## Scope of the illustrations

The ring projections illustrate different views of the digital model. They
are not optimized masks for a real printer. The two sample regions illustrate
accumulated light and a curing threshold; they are not a quantitative simulation
of resin chemistry. Durations are for explanation, not actual printing times.
Other forms of VAM use different exposure arrangements.

The mechanism follows the originating researchers' explanation:

- [Lawrence Livermore National Laboratory: 3D printing method creates objects in one piece](https://www.llnl.gov/article/45056/3d-printing-method-creates-objects-one-piece)
- [CAL software maintained by the researchers](https://github.com/computed-axial-lithography/CAL-software-Matlab)
- [Manim Community documentation](https://docs.manim.community/en/stable/)
